# BJCP Beer Exam Prep

Static single-file study app for the BJCP Beer Entrance Exam (180 Qs, 60 min, open book, pass = 116/64%). Deployed via GitHub Pages from `index.html` at repo root.

## Layout
- `src/` is the source of truth; `index.html` is GENERATED. Edit src, then run `python3 build.py`.
- `src/q1.js q2.js q3.js`: practice questions via helpers `T(sub,q,bool,expl)`, `M(sub,q,opts,idx,expl)`, `A(sub,q,opts,[idxs],expl)`. Subs: prog, bsour, bdark, eaale, lager, wheat, ipas, cpale, cdark, clager, cmixed, chars, proc (mirror the exam blueprint in `BP` in app1.js).
- `src/g1.js` study guide + fault table; `src/g2.js` flashcards.
- `src/styles.json` 2021 styles 1-26 (stats + paraphrased text), generated by `tools/parse_styles.py` from markdown notes (not in repo). Comparison questions and "highest/lowest" MCs are generated at load from these stats.
- `src/app1.js` core/dashboard/learn/flashcards; `src/app2.js` quiz/mock exam/styles/resources.
- `tools/smoke-test.js`: jsdom smoke test (`npm i jsdom`, run from repo root after build).

## Rules
- All questions must be ORIGINAL; BJCP's question pool is copyrighted. Do not paste the BJCP 124-item T/F pool.
- Keep it dependency-free, offline, no network calls. Progress lives in localStorage (key `bjcpPrepV1`), wrapped in try/catch.
- Fact-check new questions against bjcp.org (2021 guidelines; exam uses styles 1-26 only). Known source conflict: Provisional validity (Judge Ranks page says 1 yr; Exam Structure says 2 yrs; app uses 2).
