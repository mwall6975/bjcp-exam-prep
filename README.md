# BJCP Beer Exam Prep

A free, single-page study app for the BJCP Beer Entrance Exam: study guide, 300+ flashcards, 440+ practice questions, a timed 180-question mock exam, and a 2021 style reference. Progress is saved in your browser only. No build step, no dependencies.

**Live app:** https://mwall6975.github.io/bjcp-exam-prep/

## Run locally
Open `index.html` in a browser.

## Deploy (GitHub Pages)
Repo Settings > Pages > Source: "Deploy from a branch" > `main` / `(root)`.
